インテル社の元CEOであるアンドリュー・S・グローブは著書「**HIGH OUTPUT MANAGEMENT**」の中で、「_マネージャーのアウトプットは自分のチームのアウトプットと自分が影響を与えた他のチームのアウトプットの和_」であると言いました。また、言い換えればそれは「_活動領域とそのレバレッジの積の和_」であり、レバレッジとは活動領域のアウトプットに対する倍率で表される作用です。

つまるところ、マネージャーのアウトプットは以下のように表されるということです。

```
マネージャーのアウトプット
= 自分のチームのアウトプット + 自分が影響を与えた他のチームのアウトプット
= L1 ✖️ A1 + L2 ✖️ A2 + L3 ✖️ A3 + ...（活動領域とそのレバレッジの積の和）
```

同書では、1on1ミーティングについて、少ない労力で大きな組織インパクトを与えることのできる、レバレッジ効果の高いマネジメント活動であるとも言っています。ここで1on1ミーティングとは、メンターとメンティーのように、一方がもう一方の成長を期待して行う、またはより大きな成果発揮を期待して行う、1対1の対話です。

近年、1on1ミーティングにおいては、メンターとメンティーとの関係を築き、対人リスクをいとわず発言できる、いわゆる**心理的安全性**の保たれた状態を築くことが重要であると指摘されています（(本田, 2021), (由井, 2021)など）。**成功循環モデル**（ダニエル・キム）の指す「関係の質・思考の質・行動の質・結果の質のフィードバックループ」の好循環を生み出すことが、メンティーの成長や成果発揮を促進すると考えられているためです。このような関係性を生み出すために良いと言われているプラクティスが、「_1on1ミーティングの時間のうち7割〜8割はメンティーに話してもらうのが良い_」というものです。

では、残りの2割〜3割の時間でメンティーは何をするのといえば、ティーチング・コーチング・フィードバックの3つです。これらの効果を引き出すためにも、心理的安全性が確立されていることが重要であると言われています。7割〜8割メンティーに話してもらって心理的安全性を高め、高まった心理的安全性をもってティーチング・コーチング・フィードバックの効果を高めるということですね。

ティーチング・コーチング・フィードバックの目的を以下に整理します。状況に応じて3つの技法を使い分けることで、1on1ミーティングの効果を高めることができると言われています。

- ティーチング：知識の伝達
- コーチング：メンティー自身の気付きを促す、メンティー自身が課題に向き合い乗り越えることを助ける
- フィードバック：メンティーにとって耳の痛いことを含めて仕事の様子・状況がどう見えているかを伝え、成長を立て直す

1on1ミーティングの時間が仕事の進捗確認や雑談の時間になってしまう、ということが良くあると聞きます。メンティーの成長・成果、ひいては組織の成長・成果のために、メンター・メンティーの双方が1on1ミーティングに対して真剣に向き合う必要がありそうです。
